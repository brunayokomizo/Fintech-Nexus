#  Nexus - Gerenciamento Financeiro

Este é um projeto acadêmico focado em criar uma solução Fintech para ajudar os usuários a gerenciarem melhor suas finanças pessoais.

##  Status do Projeto
Em desenvolvimento. A fase atual foca na construção da interface de usuário (Front-end).

##  Tecnologias Utilizadas
* **HTML5:** Estruturação das páginas.
* **CSS3 & Bootstrap 5:** Estilização e responsividade.
* **JavaScript:** Interatividade da interface.
* **Próximos passos (Roadmap):** Migração do Front-end para React e construção da API em Java.

##  Como executar o projeto localmente
1. Faça o clone deste repositório:
   `git clone https://github.com/brunayokomizo/Fintech-Nexus.git`
2. Abra a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` para abri-lo no seu navegador padrão.

##  Funcionalidades (Visão Geral)
* Tela de Login e Cadastro.
* Dashboard de Resumo Financeiro.
* Área de Investimentos e Recebimentos.
* Gestão de Despesas.
